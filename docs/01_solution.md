# 01 · 솔루션 (무엇을·어떻게·비용)

## 한 줄 정의

> **부문 시계열 정합 에이전트** — 여러 해 DART 사업보고서에서 사업부문 매출을 뽑아,
> 이름·구조가 바뀌는 재편(rename/merge/split)을 **이합 보존**으로 관통해 하나의
> 연속 시계열로 복원하고, 모든 숫자를 출처에 결착하며, 매핑 정확도를 측정한다.

## 입출력

- **입력:** `회사명 + 회계연도 범위` (예: 네이버, 2020–2024). 사용자가 정하는 건 이것뿐.
- **출력:** 엑셀 4시트 — ①최신 구조 기준 부문 매출 **시계열**, ②구→신 **매핑 이력**
  (유형·이합잔차·신뢰도·밴드), ③모든 값의 **근거**(출처 span), ④사람이 볼 **미해결**.
- **사용자:** 부문 리서치를 하는 사람 — 애널리스트, 컨설팅 RA, 자산운용 인턴(=과거의 지원자).
  판단("이 회사가 좋은가")은 사람이 하고, 시스템은 **판단 재료를 검증 가능하게 정렬**해 준다.

## 어떻게 (핵심 알고리즘)

**이름을 믿지 말고 숫자를 믿어라.** 재편해도 겹치는 회계연도의 이합(부분합)은 보존된다.

1. **추출**(`extract/segment_extractor.py`): 사업보고서 표 → `SegmentRow`
   (부문, 회계연도, 매출, 출처 span). LLM은 제약된 추출기 — 원문에 없으면 비운다.
2. **매칭**(`reconcile/matcher.py`): 두 구조 뷰의 같은 연도 값으로 **부분합 일치** 탐색
   → identity / rename / merge(n:1) / split(1:n) / new / discontinued.
3. **정합**(`reconcile/reconciler.py`): 인접 구조쌍 매핑을 합성해 과거를 **최신 구조로 투영**,
   끊긴 시계열을 복원.
4. **결착·측정**: 모든 값이 출처 span에 묶이고, 매핑 잔차/신뢰도로 밴드
   (auto-clear / human-review / escalate) 판정.

## 챗봇/대시보드와 가르는 3층

1. **판정을 낸다** — "온랩=상품"을 이름이 아니라 4000=4000으로 검증(rename).
2. **근거에 결착** — 모든 숫자에 출처 span. 근거 없는 매핑은 미해결로 격리.
3. **채점된다** — 재분류표/이합을 정답으로 매핑 Precision/Recall. 대시보드는 자기가
   얼마나 맞는지 주장 못 한다.

## 비용 (cost)

- **데이터:** DART Open API (무료, 키 보유). 부문 표는 사업보고서 '사업의 내용'에 있음.
- **LLM:** 추출에만 사용 (Sonnet). 회사당 연도 수 × 1~2 호출. 매칭·정합·채점은 순수 계산 → 토큰 0.
- **정답:** 회사 재분류표 = 공짜. 합성 픽스처로 엔진 회귀 테스트.
- **스코프:** 학부 인턴이 1달 안에 구축 가능. v1은 한 회사·한 재편 이벤트로 좁혀 시작.

## 왜 이게 다른 후보를 이겼나 (요약)

Adverse media / 리스크 그래프 / KYB 지배구조 / fact-pack 등을 거쳐 이 지점에 수렴한 이유:
전략이 **공짜로 존재**(재분류표·이합)하고, 지원자 페인포인트·CFA·DART 경험을 정면으로 쓰고,
다섯 공고 전부에 "다중소스 정합·근거 결착·측정"으로 매핑된다.
→ 상세 결정 로그는 `docs/03_roadmap.md` 및 저장소 대화 히스토리.
